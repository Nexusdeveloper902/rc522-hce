# Contributor Covenant Code of Conduct (abridged adoption)

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1. The essentials:

- **Be respectful**: no harassment, insulting/derogatory comments, or
  unwelcome attention, in issues, PRs, reviews, or any project space.
- **Be constructive**: critique code and ideas, never people. Assume good
  faith; disagree with reasons and evidence.
- **Stay on topic**: security reports belong in the private channels in
  `SECURITY.md`, never in public issues.

## Enforcement

Violations can be reported privately to the maintainer
(`jeroperez2011@gmail.com`, also in `library.json`). Reports are handled
confidentially. Consequences range from a warning and temporary
interaction limits up to a permanent ban, at the maintainer's discretion.
Retaliation against reporters is itself a violation.
